# Shanmugaraj Senthilnathan — academic website

Academic profile in computer vision, digital construction and construction management.

Website: https://shanmugaraj1994.github.io/academic-website/

## Editing
Edit index.html for the profile and cv.html for the printable CV. Keep shared publication details consistent. styles.css controls appearance and script.js controls the carousel, filters and GIF playback.

Add your photographs under assets/gallery/ and replace the gallery placeholders in index.html with image elements using relative paths. No build step is needed. GitHub Pages serves the main branch root.

Citation count is dated and currently maintained manually. No API keys or automatic citation updater are included.
